# The Macbook
It takes me a day to get around to turning the Macbook on. After cleaning the macbook with windex, I plug it in and press the power button, eagerly awaitng the bong and thankfully it does bong.
It boots incredibly quickly, which still surprises me, I am then greeted with login screen, with a user account named User and a password. All the other computers from this lot that I have powered on have a user account named jonathon\(not really thats a placeholder\) and no password, so I'm a bit worried. I jokingly tried password and it worked, So I then factory reset the mac it takes about an hour, and I then get greated with the same login sceen, a user account named User and a password. Turns out the defualt user and password are User and password. Thanks Apple.
